## Blockers (แก้ครบแล้ว — ดู Resolution log ด้านบน)

### BLK-1 [Critical / Security] ~~Branch-scope authorization bypass~~ — **RESOLVED** — `branch_id=all`
- **ไฟล์:**
  - `backend/service/agent-invoice/src/modules/invoices/agent-invoices.controller.js:133-161`
  - `backend/service/agent-invoice/src/modules/invoices/list-invoices.query.js:9-10, 24-27`
- **OWASP:** A01:2021 Broken Access Control (intra-OU cross-branch, IDOR-class)
- **ปัญหา:** `GET /api/v1/invoices` มีเพียง `requirePermission("invoices:list")` (action permission) ไม่มี branch scope check. Controller สร้าง branch filter จาก `branch_id` ที่ client ส่งมา:
  - `branch_id=all` → ตัด branch filter → เห็นทุก branch ใน OU
  - `branch_id=<อื่น>` → query branch นั้นตรง ๆ
  - ไม่มี `branch_id` → default เป็น branch ของ caller
  - ไม่มีการเช็คว่า role ของ caller ได้รับอนุญาตข้าม branch หรือไม่
- **หลักฐาน role model:** `backend/shared/platform-roles/index.js:26-33` — `branch_admin` / `staff` อยู่นอก `BRANCH_SWITCH_ROLES` (ห้ามสลับ branch) แต่กลับเรียก `branch_id=all` อ่าน invoice ทุก branch ได้
- **Blast radius:** ภายใน OU เท่านั้น (`ouId` มาจาก `userContext` server-side เสมอ — tenant boundary ยัง safe). ไม่ใช่ cross-organization
- **ยืนยันซ้ำโดย code-reviewer:** AC-7 `useEffect` ที่เคย auto-align branch ถูกลบออก; frontend default `branch_id='all'` (`useInvoiceListFilters.ts:33`, `Invoices/utils.ts`)
- **วิธีแก้ (server-side gate):**
```js
import { canSwitchActiveBranchRole } from "@zero-platform/roles";

const wantsCrossBranch =
  rawBranchId === ALL_BRANCHES_QUERY ||
  (rawBranchId && rawBranchId !== activeBranchId);

if (wantsCrossBranch && !canSwitchActiveBranchRole(request.userContext.role)) {
  return sendError(reply, {
    statusCode: 403, code: "PERMISSION_DENIED",
    message: "Not permitted to view other branches", requestId,
  });
}
```
  สำหรับ branch-pinned roles ให้ force `branch_id = activeBranchId` เสมอ
- **ทางเลือก flip → GO:** product ยืนยันชัดเจนว่า branch ไม่ใช่ access boundary สำหรับ invoice (ผู้ถือ `invoices:list` เห็นทุก branch ใน OU ได้ตามตั้งใจ) — ถ้าเช่นนั้น downgrade เป็น Info แต่ยังต้องแก้ test coverage ที่บังหน้าปัญหา
