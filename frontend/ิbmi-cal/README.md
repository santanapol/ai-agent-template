# BMI Calculator

Demo app สำหรับคำนวณ BMI จากส่วนสูง (cm) และน้ำหนัก (kg) — pure frontend, ไม่ต้อง login

## Prerequisites

- Node.js 20+
- npm

## Quick start

```bash
npm ci
npm run dev
```

เปิด [http://localhost:5174](http://localhost:5174)

## Scripts

| Command | Description |
| :--- | :--- |
| `npm run dev` | Dev server (port 5174) |
| `npm run build` | Production build |
| `npm run test` | Unit + component tests |
| `npm run lint` | ESLint |
| `npm run preview` | Preview production build |
