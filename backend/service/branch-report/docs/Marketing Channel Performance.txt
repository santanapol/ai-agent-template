## Shared infrastructure (ทุกรายงาน)

- **Branch:** active branch จาก navbar → JWT → gateway headers (`x-user-ou`, `x-user-branch`) — ไม่รับ branchId จาก query
- **MongoDB:** DB เดียว (`MONGODB_DB_BRANCH`) + filter `ou_id` + `branch_id` ทุก query
- **Deposit สำเร็จ:** status ∈ ["001","002","004","006","007","008","009","010"]
- **Withdraw สำเร็จ:** wd_status = "200"
- **Timezone:** UTC ยกเว้น `bill_date` (+7 stored) — ห้าม $dateAdd +7
