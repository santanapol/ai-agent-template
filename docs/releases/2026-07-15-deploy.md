## Deploy

```bash
cd /var/www/zero-platform
PREVIOUS_GOOD_SHA=$(git rev-parse HEAD)
git pull origin main
bash scripts/staging/staging-verify-env.sh
bash scripts/staging/deploy-staging.sh
```

## หลัง deploy — smoke

