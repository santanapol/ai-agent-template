# Release v0.8.3 — 2026-07-15

## สรุป

แก้บั๊กแถบ pagination (Rows per page) ที่ยังไม่หายจาก v0.8.2 — คราวนี้แก้ที่สาเหตุจริง

## สิ่งที่แก้ไข

- **แถบ pagination ไม่อัปเดตหลังเปลี่ยน Rows per page** — v0.8.2 แก้ไม่ตรงจุด (แก้ที่ตัว component เอง) บั๊กเลยยังอยู่ รอบนี้แก้ที่ต้นเหตุจริง ครอบคลุมทุกหน้าที่มีตาราง: Channel Performance, Agents, Staff, Invoices, Smart Reports — เปลี่ยน Rows per page แล้วเห็นค่าใหม่ทันที ไม่ต้องสลับ tab

## ผู้ใช้ต้องทำอะไร

- ไม่ต้องทำ — เปิดหน้าที่มีตาราง แล้วลองเปลี่ยน Rows per page ดู ควรเห็นค่าถูกต้องทันทีในทุกหน้า
