# Release v0.7.0 — 2026-07-13

## สรุป

ปิด tech debt รอบ Deferred TD Closeout: bulk export invoice เร็วขึ้น (batch API), Smart Report drawer เลื่อนหน้าประวัติได้จริง, และ ops docs สำหรับ index + orphan fee cleanup

## สิ่งที่ใหม่

- **Bulk invoice export** — ดึงรายละเอียด invoice หลายใบใน **คำขอเดียว** (`GET /api/v1/invoices/batch`) แทน N× detail + transaction; progress modal ยังแสดงระหว่างสร้าง PDF/XLSX
- **Smart Report drawer** — pagination แบบ server-driven (หน้า 2+ โหลดจาก API); ไม่จำกัดแค่ 20 แถวล่าสุดใน memory

## สิ่งที่เปลี่ยน

- Harness prod baseline validators sync กับ registry (auth_users, staff_profiles, reports) — ไม่กระทบ runtime UI

## สิ่งที่แก้ไข (ops / harness — ไม่เห็นใน UI จนกว่า ops จะ apply)

- **Smart Report** — index `IDX_REPORTS_SCHEDULE_FREQUENCY` ใน code + baseline (apply บน DB ตาม ops doc)
- **agent-invoice** — audit script สำหรับ orphan `agent_fees` + runbook ลบแถว orphan (รอ human confirm บน prod)

## ผู้ใช้ต้องทำอะไร

- ไม่ต้องทำ — ล็อกอินตามปกติ
- Bulk export: เลือก invoices แล้ว export ตามเดิม; Network tab ควรเห็น **1 batch request** แทน fan-out
- Smart Report: เปิด Download History drawer แล้วเปลี่ยนหน้าได้เมื่อมีประวัติ >20 รายการ

## ยังไม่รวมในรอบนี้ (TD-035)

- รายการ Smart Report ยังใช้ `listHistory(limit=100)` ตอน mount เพื่อ badge Last run — จะย้ายไป embed ใน list API รอบถัดไป
