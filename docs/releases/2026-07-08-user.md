# Release v0.5.0 — 2026-07-08

## สรุป

Backoffice ย้ายจาก Vite (`frontend/backoffice`) มาเป็น **Next.js** (`frontend/backoffice-next`) บน staging — route parity ครบ, PM2 `zero-backoffice` พอร์ต 3005, nginx ชี้ไป Next app

## สิ่งที่ใหม่

- Backoffice Next.js — staff, agents, invoices (bulk export/status), Smart Reports, permissions, branch report, profile
- Security headers จาก Next (`X-Frame-Options`, `nosniff`, `Referrer-Policy`)
- Smart Report — server-side pagination; ประวัติ run แยกโหลดจากรายการ report

## สิ่งที่เปลี่ยน

- ลบ legacy Vite app `frontend/backoffice` ออกจาก repo
- Harness, CI, deploy scripts อ้างอิง `backoffice-next` เท่านั้น
- Invoice list — filter สอดคล้องกับ URL (debounced search, validate status)
- ข้อความ error จาก API — ไม่ส่ง raw server message ไป toast (branch report, invoice, smart report)

## สิ่งที่แก้ไข

- Auth — เมนูโหลดไม่สำเร็จแสดงว่าง + `menuError`; สลับสาขา retry ผ่าน `refreshFn` เมื่อ `AUTH_NOT_READY`
- Export CSV — escape ค่าที่มี comma/quote; ซ่อน column `select`
- ดาวน์โหลดไฟล์ Smart Report — sanitize ชื่อไฟล์จาก server

## ผู้ใช้ต้องทำอะไร

- ไม่ต้องทำ — ล็อกอิน https://zero-staging.168bits.com ตามปกติ
- หาก sidebar ว่างหลัง deploy ให้ refresh หรือ logout/login ใหม่
- Manual UAT checklist: `frontend/backoffice-next/docs/STAGING-UAT-2026-07-08.md`
