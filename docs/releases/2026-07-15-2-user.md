# Release v0.8.2 — 2026-07-15

## สรุป

แก้บั๊กแถบ pagination (Rows per page / เลขหน้า) ไม่อัปเดตทันทีหลังเปลี่ยนค่า ต้องสลับ tab แล้วกลับมาถึงจะเห็นค่าใหม่ — กระทบทุกตารางที่ใช้ pagination ร่วมกันในระบบ (Channel Performance, Agents, Staff, Invoices, Smart Reports)

## สิ่งที่แก้ไข

- **แถบ pagination ไม่ reload หลังเปลี่ยน Rows per page** — ตอนนี้ dropdown และเลขหน้าอัปเดตทันทีที่เปลี่ยนค่า ไม่ต้องสลับ tab ไปมาอีกต่อไป

## ผู้ใช้ต้องทำอะไร

- ไม่ต้องทำ — เปิดหน้าที่มีตาราง (Channel Performance, Agents, Staff, Invoices, Smart Reports) แล้วลองเปลี่ยน Rows per page ดู ควรเห็นค่าถูกต้องทันที
