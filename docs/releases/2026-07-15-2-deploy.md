## สรุป

Bugfix: `DataTablePagination` ขาด `"use no memo"` directive ทำให้ React Compiler (`reactCompiler: true` ใน `next.config.mjs`) memoize component ผิดพลาดตาม reference ของ TanStack Table's `table` object (ซึ่ง mutate internal state แต่ reference เดิมเสมอ) — ทำให้แถบ pagination ไม่ re-render ทันทีหลังเปลี่ยน Rows per page ต้องสลับ tab ถึงจะรีเฟรช แก้โดยเพิ่ม directive เดียวกับที่ `data-table-view.tsx` และ hook อื่นๆ ใช้อยู่แล้ว

UI-only, ไม่มีการเปลี่ยน API/schema/env

## Deploy

```bash
cd /var/www/zero-platform
PREVIOUS_GOOD_SHA=$(git rev-parse HEAD)
git pull origin main
bash scripts/staging/staging-verify-env.sh
bash scripts/staging/deploy-staging.sh
```
