# Release v0.8.1 — 2026-07-15

## สรุป

ปรับ UI ตาราง Deposit Matrix ใน Channel Performance ให้อ่านง่ายขึ้น ไม่มีการเปลี่ยน API หรือข้อมูล

## สิ่งที่ใหม่

- **Heat map บนตาราง Deposit count / Deposit %** — ช่องที่มีค่าสูงจะเข้มกว่าช่องที่มีค่าต่ำ ช่วยให้เห็นจุดที่คนกระจุกตัวได้เร็วขึ้นโดยไม่ต้องไล่อ่านตัวเลขทีละช่อง

## ผู้ใช้ต้องทำอะไร

- ไม่ต้องทำ — เปิด Channel Performance แล้ว Search ตามปกติ จะเห็นสีไล่ระดับในตาราง Deposit count / Deposit % ทันที
