# Release v0.8.0 — 2026-07-14

## สรุป

Channel Performance เพิ่มมุมมอง Deposit Matrix (จำนวนฝาก / % ฝาก แยกตามช่วงยอดและรอบฝากที่ 1–21) พร้อม export CSV/Excel, แก้บั๊ก rows-per-page ค้างค่าหลังสลับ branch, และปิดช่องโหว่ด้าน permission/performance ที่พบระหว่างรีวิว

## สิ่งที่ใหม่

- **Channel Performance — Deposit Matrix tabs** — แท็บ "Deposit count" และ "Deposit %" แสดงตารางจำนวน/สัดส่วนสมาชิกที่ฝากเงินแยกตามช่วงยอด (9 buckets) × รอบฝากที่ 1–21
- **Export Deposit Matrix** — ปุ่ม Export เลือกได้ทั้ง CSV และ Excel (.xlsx) จากตาราง Deposit count / Deposit %
- **Referring member dropdown** — ช่อง Channel = Member Referral ตอนนี้เลือก username ผู้แนะนำได้จาก dropdown จริง (ก่อนหน้านี้ต้องพิมพ์เอง)

## สิ่งที่เปลี่ยน

- Search Criteria เพิ่ม label "Channel" ให้ฟิลด์ channel type (ก่อนหน้านี้ไม่มี label ชัดเจน) และปรับ spacing ของแท็บให้เรียบร้อยขึ้น
- Invite Link dropdown ในหน้า Channel Performance โหลดลิงก์ล่าสุดได้มากขึ้น (limit 100 → 250) และคงค่าที่เลือกไว้เมื่อ reopen

## สิ่งที่แก้ไข

- **Rows-per-page ค้างค่าหลังสลับ branch** — เลือก 20 แถวต่อหน้าแล้วสลับสาขา ตอนนี้ dropdown แสดง 20 ถูกต้อง (ก่อนหน้านี้ค้างที่ 50)
- ตัวเลขในตาราง Deposit % ปัดเศษถูกต้องขึ้น (เคสที่ใกล้เคียงจุดกึ่งกลางเคยปัดผิด 1 จุดทศนิยม)
- CSV export ป้องกันค่าที่ขึ้นต้นด้วย `=`/`+`/`-`/`@` ถูกเปิดเป็นสูตรโดยไม่ตั้งใจเมื่อเปิดใน Excel

## ผู้ใช้ต้องทำอะไร

- ไม่ต้องทำ — ล็อกอินตามปกติ, สิทธิ์เข้าถึง Channel Performance เหมือนเดิม
- ลองเปิด Channel Performance → Search → สลับแท็บ Deposit count / Deposit % → กด Export ดูว่าไฟล์ CSV/Excel ออกมาถูกต้อง
