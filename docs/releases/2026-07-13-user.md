# Release v0.6.0 — 2026-07-13

## สรุป

อัปเดต Backoffice Next.js รอบใหญ่: ปรับ UX ให้สอดคล้อง shadcn design system, Smart Report editor v2 (หน้า create/edit แยก route), รายการ Smart Report แบบ server-side filter + history drawer, หน้า Staff profile แยก create/edit/view, และ polish ทั่ว invoices / agents / permissions / branch report

## สิ่งที่ใหม่

- **Smart Report editor v2** — `/smart-reports/new` และ `/smart-reports/:id/edit`; workflow validate → test → save; แถบสถานะ Draft/Ready
- **Smart Report list** — ค้นหา + filter enabled/schedule ฝั่ง server; drawer ประวัติดาวน์โหลดต่อ report; pagination แยกจาก enrichment history
- **Staff profile pages** — `/staff/new`, `/staff/:id`, `/staff/:id/edit`; email/tel เป็น optional; admin reset password แยกจาก self-service
- **Invoice detail** — export PDF/Excel; back navigation ผ่าน `?return=` (รองรับ refresh/deep link); แสดง currency จาก agent
- **Navigation** — เมนู sidebar ใช้ `<Link>` จริง (cmd-click, crawlable); Dashboard shortcuts เป็นลิงก์

## สิ่งที่เปลี่ยน

- รูปแบบ list page ร่วมกัน (Staff, Agents, Invoices, Smart Reports, Channel Performance, Permissions)
- Permission admin — tab Menu catalog / Role permissions; บันทึก role ผ่าน dialog (Save only / Save and revoke sessions)
- Branch switcher — เลือก inactive branch ได้ (แสดง muted); แจ้งเตือนเมื่อเปลี่ยนสาขาแล้วต้อง search ใหม่ใน branch report
- Agent fees / Staff / Agents — draft state + ปุ่ม Save แทน instant-save รายฟิลด์
- ถอด `next-themes` ใช้ `ThemeContext` ใน repo

## สิ่งที่แก้ไข

- Review findings ครบ (build, a11y, invoice amount-due, overdue badge UTC, keyboard nav dropdown ฯลฯ) — 547 tests ผ่าน
- Auth menu error state; invoice list URL sync; Smart Report drawer stale-response guard
- Staff service — normalize email/tel เป็น null เมื่อว่าง; Smart Report sandbox projection สำหรับ test-run preview

## ผู้ใช้ต้องทำอะไร

- ไม่ต้องทำ — ล็อกอินตามปกติ
- Smart Report: ต้อง validate + test script ก่อน save (ถ้าแก้ query)
- Permission admin: หลัง save role ผู้ใช้อาจต้อง refresh session หรือ admin เลือก "Save and revoke sessions"
- หลัง deploy หาก sidebar/เมนูผิดปกติ ให้ logout/login หรือ hard refresh
