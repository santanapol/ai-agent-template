# Release — 2026-07-07

## สรุป

Backoffice โหลดรายการสาขาจากระบบยืนยันตัวตนโดยตรง ตัวสลับสาขาเสถียรขึ้น และมีเครื่องมือ staging deploy/smoke สำหรับทีม ops

## สิ่งที่ใหม่

- รายการสาขาที่ผู้ใช้เข้าถึงได้จาก auth (`GET /auth/me/branches`) แทน agent-invoice
- ตัวสลับสาขาแสดง Zero HQ และสาขาลูกค้าเรียงตามกฎเดียวกันทั้งระบบ

## สิ่งที่เปลี่ยน

- เมนู Branch Report — Channel Performance อยู่ใต้ Branch Report โดยตรง (ไม่มีเมนู Marketing แยก)
- หน้า Login ใช้ฟอร์มที่แยก component ชัดเจนขึ้น

## สิ่งที่แก้ไข

- สลับสาขาหลัง login ทำงานได้แม้ token ยังไม่พร้อม (retry อัตโนมัติ)
- smart-report บล็อก pipeline write stages (`$out` / `$merge`) ทั้งตอน validate และตอนรัน

## ผู้ใช้ต้องทำอะไร

- ไม่ต้องทำ — ล็อกอินและใช้ตัวสลับสาขาตามปกติ
- หาก sidebar เมนูไม่ตรงหลังอัปเดต staging ให้แจ้งทีม ops (อาจต้อง re-seed สิทธิ์บน staging)
