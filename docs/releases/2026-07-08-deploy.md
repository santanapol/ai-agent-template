## Deploy

```bash
cd /var/www/zero-platform
PREVIOUS_GOOD_SHA=$(git rev-parse HEAD)
git pull origin main
bash scripts/staging-verify-env.sh
bash scripts/deploy-staging.sh
```

`deploy-staging.sh` ensures swap on 2GB droplet, skips `install-all-deps` when lockfiles unchanged, runs `npm run build:staging` in `frontend/backoffice-next`, then `pm2 reload ecosystem.staging.config.js`.

- Nginx updated from Vite static `/assets/` to Next proxy `:3005`; HTTPS `:443` restored.
- Server at `7aed652`; all PM2 apps online.
