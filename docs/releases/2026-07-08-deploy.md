## Deploy

```bash
cd /var/www/zero-platform
PREVIOUS_GOOD_SHA=$(git rev-parse HEAD)
git pull origin main
bash scripts/staging-verify-env.sh
bash scripts/deploy-staging.sh
```

`deploy-staging.sh` runs `npm run build:staging` in `frontend/backoffice-next` then `pm2 reload ecosystem.staging.config.js`.

## หลัง deploy — smoke

```bash
SMOKE_PASSWORD='…' bash scripts/smoke-staging.sh
```

จากเครื่อง dev (หลัง staging deploy):

```bash
SMOKE_PASSWORD='…' STAGING_URL=https://zero-staging.168bits.com bash scripts/smoke-staging.sh
```

## Post-smoke — git tag

```bash
git fetch origin main && git checkout main && git pull
./scripts/release-tag.sh v0.5.0
```

## Rollback

```bash
cd /var/www/zero-platform
git fetch origin && git reset --hard v0.4.0   # or PREVIOUS_GOOD_SHA
bash scripts/deploy-staging.sh
```
