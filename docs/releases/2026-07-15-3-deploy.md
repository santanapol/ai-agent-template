## สรุป

Root-cause fix for the Rows-per-page pagination bar not updating — v0.8.2's fix (`"use no memo"` on `DataTablePagination.tsx` itself) targeted the wrong layer. React Compiler caches the `<DataTablePagination table={table} .../>` **JSX element at the call site**, not the component body: since TanStack Table's `table` object keeps a stable reference across renders (it mutates in place) and the sibling props (`total`, `pageSizeOptions`) also don't change on a plain page-size interaction, the compiler treats the call site as "unchanged" and reuses the previously rendered element — so `DataTablePagination` never gets re-invoked with the new `pageSize`, regardless of any directive inside that file.

Verified by building the app locally with the real `next.config.mjs` (React Compiler enabled) and driving it with Playwright against an isolated debug route — confirmed the bug disappears with `reactCompiler: false` and reappears with it re-enabled, then confirmed the fix must live in the **caller**, not the callee.

Fix: added `"use no memo"` to the four caller components that create `<DataTablePagination>` and didn't already have it (`Royalty21Table.tsx`, `AgentsList.tsx`, `StaffTable.tsx`, `SmartReportList.tsx`). `InvoiceList.tsx` already had it from earlier work, which is why Invoices was never affected.

```bash

```
