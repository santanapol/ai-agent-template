# Staff service — feature plans

เก็บแผนงาน spec-driven สำหรับฟีเจอร์ staff ที่ต้องผ่าน gated workflow

## Naming convention

```
YYYY-MM-DD-<feature-slug>.md
```

ตัวอย่าง: `2026-07-15-department-filter.md`

## Workflow

1. อ่าน [staff-spec.md](../staff-spec.md) และ [WORKFLOW.md](../WORKFLOW.md)
2. สร้าง plan file ในโฟลเดอร์นี้
3. อัปเดต spec (business-domain / openapi) ก่อน implement
4. ลบหรือ archive plan เมื่อฟีเจอร์ ship แล้ว (optional)

## Template

ดู plan file template ใน [WORKFLOW.md](../WORKFLOW.md)
